# Phantom TT Hub - TikTok No Watermark + All Platforms
Fullstack Vercel: Frontend + Backend in one repo

## Deploy to Vercel:
1. Push these files to GitHub
2. Vercel -> New Project -> Import repo -> Deploy

## Structure:
- index.html = Frontend (paste TikTok link)
- api/index.py = Backend (Python Flask + yt-dlp + tikwm no-watermark API)
- vercel.json = Routes frontend + backend
- requirements.txt = Dependencies (FIXED)

## Features:
- TikTok NO WATERMARK (via tikwm API + yt-dlp)
- Also: Instagram, Facebook, X, Pinterest, YouTube, Any link
- History saved in backend
